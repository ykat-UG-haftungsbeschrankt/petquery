    🐾 petquery

    One search. Every registry. Bring lost pets home — across borders.

    Website · Repository · API docs

    💡 Why petquery?

    When a pet goes missing, most national authorities only search the national and local registries that hold owner information. A pet that travelled with its owner, or wandered over a border, can end up in a database nobody thinks to check.

    petquery is a small, plugin-based meta search engine for pet microchip IDs. You enter one query, it asks every configured registry at the same time, and it returns a single combined result.

    ✨ Features

    • 🔌 Plugin-based: every data source is a plugin. Use the built-in ones or write your own in a few lines.
    • ⚡ Parallel queries: all plugins are queried at the same time. One slow or failing source never blocks the others.
    • 🌍 Federated: petquery servers can query each other, so authorities can share their local data without sharing their database.
    • 🔁 Loop-safe: each server has its own UUID, and queries carry a traceroute of the servers they have passed through, so loops between federated servers can be spotted.
    • 🛡️ Validated I/O: incoming and remote JSON is checked with cast.ts before it is used.
    • 🔐 Bearer authentication for the machine-facing endpoints.
    • 📎 File uploads: photos or documents can be attached to a query and are passed on to the plugins.

    🧭 How it works

    flowchart LR
        U([🧑 User / Authority]) -->|query| S[🐾 petquery server]
        S --> A[animalid.by]
        S --> M[(MySQL)]
        S --> D[(MongoDB)]
        S --> P[🐾 another petquery server]
        A & M & D & P -->|results| S
        S -->|merged result| U

    🚀 Quick start

    git clone https://github.com/ykat-UG-haftungsbeschrankt/petquery.git
    cd petquery
    npm install
    npm start

    npm start lints and compiles the TypeScript sources to native ES modules in dist/, then starts the server on http://127.0.0.1:50000/.

    Tip

    In VS Code, use the Launch PetQuery debug configuration. It builds the project, starts the server and opens it in your browser.

    ⚙️ Configuration

    All settings are in src/pet/query/config.ts:

    Setting What it does
    server.http / server.https Ports, on/off switches and the TLS certificate
    server.authenticate.bearer The bearer tokens accepted by /json and /api
    server.file.upload File upload switch and limits (10 MB by default)
    server.max_results_per_module Maximum number of results kept per plugin
    server.max_results_total Maximum number of results in a response
    server.route Turns each endpoint on or off and sets its authentication
    plugin One entry per plugin: on/off, timeout, source and settings
    Important

    Replace the example bearer tokens with your own secrets before you deploy.

    🌐 Endpoints

    Endpoint Auth Returns Turned on by
    / — HTML search page route["/"].enabled
    /json 🔐 Merged results from all plugins route.json.enabled
    /api 🔐 Results from one plugin only route.api.enabled

    Every endpoint accepts GET query strings, JSON or form POST bodies, and multipart/form-data file uploads.

    Parameter Type Description
    query string The pet ID to look up, e.g. a microchip number
    tracerouteUuid uuid[] Servers the query has passed through (federation)

    /json: search everything

    Use this to show petquery results on your own website or in your own application.

    JavaScript 
    const response = await fetch('https://petquery.org/json', {
    	method: 'POST',
    	headers: {
    		'accept': 'application/json',
    		'content-type': 'application/json',
    		'authorization': 'Bearer <your-token>'
    	},
    	body: JSON.stringify({query: '112093400000465'})
    });
    if(!response.ok){
    	throw new Error(response.statusText);
    }
    console.log(await response.json());
    PHP 
    #!/usr/bin/php
    <?php

    $result = file_get_contents(

    /api: share your own registry

    /api returns results from the single plugin named in route.api.module, as a plain array of result entries.

    This is how authorities share their data. Run petquery next to your local database, expose it through /api, and give other petquery servers a token. They add your server as a petquery plugin, with your URL and token in their config, and your registry becomes part of their search. Your database itself is never exposed.

    const response = await fetch('https://petquery.org/api', {
    	method: 'POST',
    	headers: {
    		'content-type': 'application/json',
    		'authorization': 'Bearer <your-token>'
    	},
    	body: JSON.stringify({query: '112093400000465'})
    });
    console.log(await response.json());

    🔌 Plugins

    Plugin Source
    animalid.by The animalid.by registry
    mysql Any MySQL / MariaDB table, using a configurable SQL template
    mongodb Any MongoDB collection, matched on uid
    petquery Another petquery server (federation)
    test / error Fixed sample data and error output, for development

    Writing your own plugin

    A plugin is a class that extends PetQueryPlugin. It receives the query and returns a result:

    import {PetQueryPlugin} from '#petquery/plugin.js';
    import {PetQueryPluginQuery} from '#petquery/plugin/query.js';
    import {PetQueryPluginResult} from '#petquery/plugin/result.js';
    import {PetQueryPluginMyRegistryConfig} from
    	'#petquery/plugin/my/registry/config.js';

    export class PetQueryPluginMyRegistry extends PetQueryPlugin{
    	constructor(cfg:PetQueryPluginMyRegistryConfig){
    		super('my-registry',cfg);
    	}

    	override async query(
    		query:PetQueryPluginQuery
    	):Promise<PetQueryPluginResult>{
    		const rows = await lookUp(query.getQuery());
    		return PetQueryPluginResult.fromJson(rows.map((row)=>{
    			return {
    				source:this.getSource().toJson(),
    				preview:'',
    				files:[],
    				attributes:row
    			};
    		}));
    	}
    };

    Then add its config to the plugin map in config.ts and register it in index.ts:

    server.addPlugin(new PetQueryPluginMyRegistry(
    	PetQueryConfig.getPluginConfig(
    		PetQueryPluginMyRegistryConfig,
    		'my-registry'
    	)
    ));
